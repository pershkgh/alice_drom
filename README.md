# Домашняя музыка — навык для Алисы

[![ci](https://github.com/pershkgh/alice_drom/actions/workflows/ci.yml/badge.svg)](https://github.com/pershkgh/alice_drom/actions/workflows/ci.yml)
[![license: MIT](https://img.shields.io/badge/license-MIT-6C5CE7.svg)](LICENSE)

Голосовое управление **своей** музыкальной библиотекой на Яндекс.Станции:
«Алиса, запусти навык Домашняя музыка» → «включи эванесенс», «перемешай»,
«громкость 3», «что играет», «избранное», «похожее».

Ничего не грузится в облако: музыка играет с вашего сервера, навык — только
пульт, который отправляет команды в Music Assistant.

```
  Алиса (колонка)
        │  голос
        ▼
  Яндекс.Диалоги ──HTTPS──► навык (этот проект, :8100)
                                  │ JSON-RPC
                                  ▼
                          Music Assistant (:8095)
                                  │  библиотека + поток
                                  ▼
                             Navidrome (:4533)
                                  │
                                  ▼
                        ваша папка с музыкой
```

## 🧰 Что нужно

| | Требование |
|---|---|
| Сервер | Linux с Docker и Docker Compose v2 (2 ГБ RAM хватит) |
| Сеть | **домен**, указывающий на сервер, открытые 80/443 |
| Музыка | Navidrome (или любой Subsonic-совместимый сервер) с просканированной библиотекой |
| Колонка | Яндекс.Станция (любая, привязанная к вашему аккаунту) |
| Аккаунт | Яндекс-аккаунт — для провайдера станции в Music Assistant |

Music Assistant нужен обязательно — это слой, который умеет играть на станции.
**Если его нет — не беда:** в комплекте есть готовый образ с рабочим провайдером
станции (`ma-station/`), инсталлер поднимет его сам.

После установки в Music Assistant нужно один раз подключить свою библиотеку:
**Настройки → Провайдеры → OpenSubsonic (Navidrome)** → адрес вашего Navidrome,
логин и пароль → сохранить. Дальше треки находятся поиском, а навык ими управляет.

## 🚀 Установка

> Подробное пошаговое руководство со скриншотами — **[docs/MANUAL.md](docs/MANUAL.md)**
> (домен, Music Assistant, Яндекс.Диалоги, приложение, разбор поломок).

```bash
git clone https://gitlab.com/<ваш-ник>/alice-music.git
cd alice-music
./install.sh
```

Инсталлер спросит четыре вещи (домен, email, параметры Music Assistant, станцию),
сгенерирует `.env` с правами 600, поднимет контейнеры и проверит связь.

Дальше — два шага руками, их нельзя автоматизировать:

1. **dialogs.yandex.ru/developer** → «Создать диалог» → «Навык для Алисы» →
   в поле **Webhook URL** вставить `https://ВАШ-ДОМЕН/alice` → сохранить.
   Статус **«Черновик»** достаточно, модерация не нужна.
   ⚠️ **Не публикуйте навык**: публичный навык доступен всем, а управляет он
   **вашей** колонкой.
2. Скажите колонке: **«Алиса, запусти навык Домашняя музыка»**.

Проверка после установки:

```bash
./doctor.sh
```

Покажет цепочку «навык → MA → станция → поток → библиотека» и что именно
сломалось, если сломалось.

## 🎤 Что умеет

| Скажите | Что произойдёт |
|---|---|
| «включи эванесенс», «поставь сплин» | поиск по библиотеке и воспроизведение |
| «дальше», «назад», «пауза», «продолжи», «стоп» | транспорт |
| «громкость 3», «громче», «тише» | громкость 0–10 |
| «перемешай», «по порядку» | режим перемешивания |
| «повтори», «повтори все», «выключи повтор» | повтор |
| «что играет» / «кто это поёт» | текущий трек, исполнитель, альбом |
| «избранное» | любимые треки |
| «похожее» | похожее на текущий трек |
| «лайк» | добавить в избранное |
| «перемотай на минуту», «в начало» | позиция в треке |
| «запусти навык …» | повторный запуск |

## 🖥️ Веб-пульт и API

Навык отдаёт небольшой API — им пользуется приложение для Windows и диагностика.

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/status` | состояние станции, трек, очередь |
| POST | `/api/command` | выполнить фразу (`{"text":"дальше"}`) |
| GET | `/api/events` | журнал: что говорили и что произошло |
| GET | `/api/queue` | очередь с обложками |
| GET | `/api/diagnostics` | проверка всей цепочки |
| GET | `/health` | живость (без токена, для мониторинга) |

Все `/api/*` закрыты токеном `API_TOKEN` из `.env` (заголовок `X-Api-Token`).
Наружу публикуется только `/alice` — его проксирует Caddy, остальное остаётся
в локальной сети.

## 🪟 Приложение для Windows

**Готовый файл** — в разделе [Releases](../../releases): `MusicControl.exe` (~110 КБ,
.NET Framework 4.8 уже есть в Windows). При первом запуске откроется экран
«Настройки»: впишите адрес навыка и `API_TOKEN` — конфиг создастся сам. Собрать самому:


```bash
cd windows
dotnet build -c Release     # → bin/Release/net48/MusicControl.exe (~110 КБ)
```

Получится один `MusicControl.exe` (~110 КБ, .NET Framework 4.8 уже есть в Windows 10/11):
плеер, журнал, диагностика, очередь с обложками. В `windows/config.json`
задаётся в самом приложении (раздел «Настройки»).

## 🩺 Если что-то не работает

| Симптом | Куда смотреть |
|---|---|
| Навык молчит, Алиса «не понимает» | `./doctor.sh`; проверьте, что `ping` доходит из Диалогов |
| Музыка «играет», а звука нет | диагностика: строка «Поток на колонку (8097)» |
| Колонка не найдена | провайдер Яндекс.Станции в MA: аккаунт, 2FA, версия провайдера |
| `Draft is not allowed to deploy` | это про публикацию; для черновика неважно |
| Тишина после обновления станции | провайдер станции отстал от прошивки — обновите `ma-station/` |

Подробнее: [`docs/TROUBLESHOOTING.md`](docs/TROUBLESHOOTING.md).

```bash
git pull

```

## 🔒 Безопасность

- Секреты живут только в `.env` (600) и в git не попадают.
- Наружу открыт один путь — `/alice`; он проверяет подпись Яндекса.
- API пульта закрыт токеном; не публикуйте порт 8100 в интернет без него.
- Пароль от Яндекс-аккаунта вводится **в Music Assistant**, а не в этот проект.
