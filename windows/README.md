# Пульт для Windows

<p align="center"><img src="icon-512.png" width="112" alt="Иконка пульта"></p>

Одно окно вместо консоли: плеер, журнал, диагностика и очередь с обложками.

## Не хочу собирать — дайте готовый файл

Откройте **Releases** репозитория и скачайте `MusicControl.exe` (он там с версии `v1.0.0`).
Рядом положите `config.json` из того же релиза и впишите свой адрес сервера и `API_TOKEN`.

## Сборка

Нужен .NET 8 SDK (или соберитесь в CI — см. `.gitlab-ci.yml`, job `windows:exe`).

```bash
cd windows
dotnet build -c Release
# → bin/Release/net48/MusicControl.exe
```

Получится `bin/Release/net48/MusicControl.exe` — **около 135 КБ**.

Если у пользователя нет .NET Framework 4.8 (или Windows отвечает «Невозможно запустить это
приложение на вашем ПК»), соберите самодостаточную версию — рантайм будет внутри:

```bash
dotnet publish -c Release -r win-x64 --self-contained true \
  -p:FullBuild=true -p:PublishSingleFile=true \
  -p:IncludeNativeLibrariesForSelfExtract=true \
  -p:EnableCompressionInSingleFile=true -o publish-full
# → publish-full/MusicControl.exe (~66 МБ)
```

Приложение собрано под **.NET Framework 4.8**: он входит в Windows 10 (начиная с 1903)
и Windows 11, поэтому доустанавливать ничего не нужно. Собирается и на macOS/Linux:
для этого в проект добавлен пакет `Microsoft.NETFramework.ReferenceAssemblies`.

## Первый запуск

Ничего руками создавать не нужно: приложение при старте откроет **«Настройки»** —
впишите адрес сервера (`192.168.1.10:8100` или ваш) и `API_TOKEN` из `.env`,
нажмите «Проверить связь» → «Сохранить». Конфиг создастся сам.

Если хотите подготовить файл заранее, положите рядом с exe `config.json`:

```json
{
  "baseUrl": "http://192.0.2.10:8100",
  "apiToken": "ваш API_TOKEN из .env"
}
```

Кнопка «Открыть config.json» в настройках показывает, где лежит этот файл.

## Что внутри

| Раздел | Что делает |
|---|---|
| Домой | текущий трек, прогресс, громкость, быстрые действия, журнал, поле фразы |
| Проверка | диагностика цепочки навык → MA → станция → поток → библиотека |
| Очередь | что играет дальше, с обложками; клик — включить трек |

Токен нужен потому, что `/api/*` закрыт: приложение шлёт его в заголовке `X-Api-Token`.

## Если Windows ругается

SmartScreen на неподписанный exe: «Подробнее» → «Выполнить в любом случае»,
либо снимите блокировку в свойствах файла («Разблокировать»).
