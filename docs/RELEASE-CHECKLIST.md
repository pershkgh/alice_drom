## Известные ограничения (честно написать в README)

- Провайдер станции зависит от прошивки: после обновления станции музыка может замолчать
- Работает один навык = одна квартира; публичный навык делать нельзя
- Нужен домен с HTTPS: Яндекс не умеет стучаться по IP
- Linux + Docker; Windows/macOS-хост не поддерживается (нужен `/proc/net/tcp` для диагностики)
