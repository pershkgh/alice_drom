# История изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [SemVer](https://semver.org/lang/ru/).

## [1.0.0] — 2026-11-22

Первый публичный выпуск.

### Добавлено

- Навык для Алисы (FastAPI): транспорт, громкость 0–10, перемешивание, повтор,
  «что играет», избранное, «похожее», лайк, перемотка, поиск по библиотеке.
- Music Assistant: JSON-RPC-клиент, очередь, обложки через `/imageproxy`, поток на 8097.
- Диагностика `/api/diagnostics` и `./doctor.sh` с человеческими подсказками.
- HTTP-API для пульта: `/api/status`, `/api/command`, `/api/events`, `/api/queue`,
  `/api/play-index`, `/api/cover`, `/api/diagnostics`.
- `install.sh`: проверка окружения, домен, выбор ветки Music Assistant, свой или
  встроенный Caddy, генерация `API_TOKEN`, ожидание готовности и проверка станции.
- Образ `ma-station`: Music Assistant 2.10.12 + провайдер станции 1.7.9
  (на актуальных прошивках штатный провайдер не играет).
- Пульт для Windows (WPF, .NET Framework 4.8, ~110 КБ): плеер, журнал, диагностика,
  очередь с обложками, экран настроек подключения, одна кнопка-ссылка на проект.
- Имя навыка — настройка (`SKILL_NAME`), а не константа; приложение показывает его в шапке.
- Документация: `docs/MANUAL.md` (пошагово со скриншотами), `docs/SETUP.md`,
  `docs/TROUBLESHOOTING.md`, `docs/ARCHITECTURE.md`, `docs/YANDEX-STATION.md`.
- CI: проверка синтаксиса, `docker compose config`, сборка образа в GHCR,
  сборка exe и релиз по тегу `v*`.

### Известные ограничения

- Навык не публикуется: только «Черновик» для личного аккаунта.
- Колонка должна быть доступна по локальной сети серверу.
- Публичный HTTPS-домен обязателен — Яндекс не принимает IP.
- Голосовой поиск работает по подстроке: сложные запросы («каверы 90-х») не понимает.
